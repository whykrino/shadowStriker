# Roadmap

## Геймплей

- [ ] Оружие на выбор перед забегом: катана, одати, кусаригама, сюрикены
- [x] Заряженная атака: держишь ПРОБЕЛ 0.6 сек, получаешь усиленный удар (урон скейлится от времени удержания)
- [x] Backstab: удар в спину даёт x2 урона
- [x] Вихрь на T: круговой удар, +10% урона, персонаж поворачивается на 360 и делает финальный выпад
- [x] Блок на ПКМ: поглощает урон до (10 + level * 2), при превышении пробивается, кулдаун 1.5 сек
- [x] Рывок: 3 заряда, восстановление по одному (SHIFT)
- [ ] Комбо за серию ударов: баффы на 10 / 25 / 50
- [ ] Прыжок и атака в воздухе
- [ ] Способности посерьёзнее: сюрикен, дымовая завеса

## Мобы

- [x] Призрак: проходит сквозь стены, бьёт только со спины
- [x] Шаман - лечит других мобов рядом
- [x] Червь - при смерти делится на двух маленьких
- [x] Летун - стреляет сверху, уязвим когда садится
- [x] Страж - стоит на месте, бьёт дальним лучом
- [x] 7 базовых и 5 новых архетипов: слизень, голем, стрелок, убийца, призыватель, камикадзе, босс, призрак, шаман, червь, летун, страж
- [x] Боссы каждые 10 уровней
- [x] Позиционный рёв мобов
- [ ] Мини-боссы в каждой зоне, раз в 3-4 минуты
- [ ] Уникальные паттерны для каждой фазы босса, а не просто меньше HP

## Мир

- [x] Процедурная текстура земли
- [x] Процедурные деревья и руины
- [x] Коллизии с камнями и деревьями
- [x] Мини-карта с метками опасности
- [ ] Больше биомов: снег, лава, болото, руины
- [ ] Бочки, которые взрываются при ударе
- [ ] Ящики с лутом
- [ ] Святилища, где восстанавливается HP
- [ ] Шипы, которые бьют всех: и игрока, и мобов
- [ ] Порталы между зонами
- [ ] Разрушаемые стены

## Прогрессия

- [x] Дерево талантов на 20 узлов
- [x] Лут: HP, опыт, баффы
- [ ] Сохранять прогресс в localStorage: уровень, таланты, рекорды
- [ ] Мета-прокачка между забегами, как в Hades
- [ ] Аффиксы на оружии: скорость, вампиризм, заморозка
- [ ] Редкость предметов: обычное, редкое, эпическое, легендарное
- [ ] Бесконечный режим с волнами
- [ ] Кооп на двоих, сплит-скрин

## Визуал

- [ ] Спрайты вместо фигур, или скелет с нормальными картинками
- [ ] Кровь и брызги при ударах
- [ ] Дымка при рывке
- [ ] Частицы окружения: листья, снег, пыль
- [ ] Тряска камеры на сильных ударах и смерти боссов
- [ ] Zoom-in когда убиваешь босса
- [ ] Искажение цвета при низком HP
- [ ] Освещение: фонари, светящиеся мобы, туман
- [ ] Диалоги и подсказки на карте

## Звук

- [x] Музыка и звуки
- [x] Меню звука
- [ ] Разная музыка для зон с плавными переходами
- [ ] Позиционные шаги мобов, чтобы слышать кто подходит
- [ ] Отдельный звук для крита и бэкстаба
- [ ] Звук зарядки атаки, нарастающий тон
